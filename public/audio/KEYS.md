# Narration files – names the app looks for

Put each MP3 in this folder with exactly this file name, then add the name (without .mp3) to `index.json`.
A speaker button appears only for files listed in `index.json`, so missing files never show a broken button.

Rule for any English line: lower case, keep letters and numbers, every space or punctuation mark becomes one `-`,
apostrophes are dropped. Example: “Read the word. Choose the picture.” → `read-the-word-choose-the-picture.mp3`.
Single words start with `w-`: cat → `w-cat.mp3`.
