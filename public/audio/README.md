# Audio folder

1. Record each line as an MP3 (short, clear, no music).
2. Name it as listed in KEYS.md and copy it here.
3. Add its name to index.json, e.g. `["read-the-word-choose-the-picture", "w-cat"]`.
4. Push to GitHub – Cloudflare publishes it and the speaker button appears next to that line.
